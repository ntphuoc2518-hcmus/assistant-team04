## Data Verification Criteria

Before using or updating a data file, verify the following:

- **Source reliability:** Confirm that the data comes from a known, trustworthy source.
- **Accuracy:** Check that values are correct and consistent with the original source.
- **Completeness:** Ensure that required fields are present and important values are not missing.
- **Format consistency:** Verify that column names, data types, CSV delimiters, and encoding follow the project's requirements.
- **Duplicate records:** Identify and remove unintended duplicate entries.
- **Validity:** Check that values follow the expected rules and allowed ranges.
- **Freshness:** Confirm that the data is up to date and appropriate for its intended use.

## Update Guidelines

- Verify data before adding it to the project.
- Keep the file format consistent with the application's requirements.
- Update this README whenever a data file is added, removed, or modified.
- Record the data source, owner, and update frequency for each file.
- The file owner is responsible for maintaining data accuracy and documentation.
